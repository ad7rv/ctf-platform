⏪ The Internet Never Forgets

The developer of this CTF platform made a classic mistake: they accidentally committed a file with an admin backup code to the public source repo... then deleted it in a panic with a commit titled "remove leaked file".

Deleting a file doesn't erase history. git remembers everything.

  • The source code of this site lives at github.com/ad7rv/ctf-platform
  • Browse the repository's commit history — look for that panicked commit.
  • "Files changed" in the earlier commit contains the leaked file and its contents.
  • git users: git log --oneline then git show.
