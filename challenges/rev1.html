🔓 Reverse the XOR

The program below was found protecting a flag. It doesn't print the flag directly — it stores obfuscated bytes and only decodes them at runtime. Read the code, figure out what it does, and recover the flag.

(Yes, you could just run it in your DevTools console. Understanding why it works is the real challenge.) 

// 🔒 flag-protection.js — definitely uncrackable
const cipher = [1, 22, 4, 57, 48, 113, 52, 113, 48, 49, 113,
                29, 54, 42, 113, 29, 58, 114, 48, 63];
const mask = 0x42;
let out = "";
for (let i = 0; i < cipher.length; i++) {
  out += String.fromCharCode(cipher[i] ^ mask);
}
console.log(out);
  • XOR is reversible: cipher ^ mask = original
  • Hint #1: 0x42 in decimal is 66.
  • Hint #2: paste the whole script into your browser console (F12).
  • Hardcore path: decode the numbers by hand on paper. 🧠
