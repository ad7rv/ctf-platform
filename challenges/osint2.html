🌿 Branch Out

Everyone stares at main. But repositories often grow other branches — experiments, half-finished features, and developer secrets. One extra branch exists in this site's repo, and it's hiding the flag.

  • Repo: github.com/ad7rv/ctf-platform
  • On GitHub: click the branch dropdown (usually says "main") — how many branches are there?
  • Or clone it: git clone then git branch -a and git checkout the odd one.
  • Look for a file that only exists on that branch.
