📡 Dit Dah

Pickup from a ham-radio operator. Spaces separate letters:

-.-. - ..-. { -.. .---- - _ -.. ....- .... _ -.. .---- - }
  • This is Morse code. Letters and digits have patterns; {, _, } stay as-is.
  • Any "Morse code translator" online will decode it.
  • Morse is caseless — decoders output ALL CAPS. Submit the all-caps result exactly as decoded.
