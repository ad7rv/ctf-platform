🧩 Crack the Check

This license-key validator checks the input character by character. It never stores the full flag in one place... but the source is right below. Assemble the pieces. 

function validate(key) {
  const parts = [
    "CTF{",
    String.fromCharCode(99, 104, 52, 114),          // 4 chars
    "_by_",
    "c" + "h" + String.fromCharCode(52) + "r",      // 4 chars
    "_c" + "h" + "3" + "ck",
    "}"
  ];
  return key === parts.join("");
}
  • String.fromCharCode(99, 104, 52, 114) — what string is that?
  • Paste the array pieces into your console and .join("").
  • Or decode character codes by hand with an ASCII table.
